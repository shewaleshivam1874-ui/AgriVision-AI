1. PROJECT NAME
================================================================================
AgriVision AI (Explainable Crop Disease Detection & Plant Pathology Health Analysis)

================================================================================
2. PROJECT OVERVIEW
================================================================================
AgriVision AI is an Explainable Artificial Intelligence (XAI) and Computer Vision web platform built to provide instant, accessible, and scientifically grounded crop health diagnosis. Farmers, agricultural extension officers, researchers, and agronomists can upload or capture close-up photographs of crop foliage to receive an immediate preliminary diagnosis.

The system features a hybrid dual-engine AI architecture:
1. Primary Production Cloud Vision Engine: Google Gemini Vision AI (Gemini 2.5 Flash / Gemini 3.6 Flash) integrated via google-genai / google-generativeai SDKs, delivering deep structured pathology analyses including botanical identification, disease condition classification, visual symptom breakdown, 4-tier severity staging, nutrient deficiency analysis, pest damage detection, environmental stress assessment, separate organic and conventional chemical management guidance, and a prioritized 4-step immediate action journey.
2. Local Offline Classical ML Engine: A TensorFlow / Keras deep convolutional transfer learning architecture (EfficientNetB0 / MobileNetV2) trained on 38 crop disease classes with integrated OpenCV image quality screening, HSV-based leaf lesion segmentation, severity percentage calculation, and Grad-CAM (Gradient-weighted Class Activation Mapping) saliency heatmaps.

The platform provides full multilingual localization across English (en), Marathi (mr), and Hindi (hi) at both server template rendering and real-time client DOM manipulation levels. It utilizes MySQL with automatic, zero-configuration SQLite fallback for persistence of diagnostic logs and agricultural reference data.

================================================================================
3. PURPOSE OF THE WEBSITE
================================================================================
- Early Disease Detection: Detect foliar fungal, bacterial, viral, pest, and nutrient disorders before severe crop loss or canopy collapse occurs.
- Transparent AI Explainability: Bridge the trust gap between machine learning models and farmers by providing visual heatmap attention (Grad-CAM), lesion segmentation overlays, and plain-language symptom explanations.
- Actionable Guidance: Provide farmers with immediate, practical steps categorized into organic bio-controls, conventional chemical active ingredients, and fertilizer adjustments.
- Vernacular Language Inclusivity: Make precision agriculture accessible to non-English-speaking smallholder farmers in India by offering native Hindi and Marathi interfaces.
- Historical Diagnostic Tracking: Allow farmers and agronomists to maintain a persistent audit trail of past crop health assessments with severity filtering and trend monitoring.

================================================================================
4. MAIN OBJECTIVES
================================================================================
1. Real-Time Leaf Pathology: Provide sub-second to low-latency foliar diagnostic feedback on mobile and desktop web browsers.
2. Dual-Model Robustness: Enable high-precision cloud LLM vision diagnostics with offline CNN/XAI fallback capability.
3. Out-of-Distribution & Image Quality Rejection: Prevent erroneous predictions by algorithmically validating blur, brightness, contrast, resolution, and green foliage ratios before AI inference.
4. Structured Agricultural Safety: Prevent indiscriminate chemical use by separating organic biocontrol options from conventional treatments, enforcing active ingredient naming over commercial brand names, and emphasizing mandatory safety disclaimers.
5. Persistent Audit Trail: Log diagnoses into database storage with search, severity filtering, and JSON snapshot retrieval.

================================================================================
5. TARGET USERS
================================================================================
- Smallholder & Commercial Farmers: Seeking rapid in-field identification of crop distress and step-by-step organic or conventional remediation guidance.
- Agricultural Extension Workers & Field Agents: Providing diagnostic consultations and verifying disease spread across regional farms.
- Agronomists & Crop Advisors: Conducting preliminary assessments and reviewing historical disease frequency.
- Agricultural Researchers & Students: Studying plant pathology, deep learning transfer learning, Grad-CAM attention mechanisms, and multilingual agricultural interfaces.

6. COMPLETE TECHNOLOGY STACK
================================================================================
Frontend:
- HTML5: Semantic markup with microdata and accessibility attributes.
- CSS3: Pure Vanilla CSS Design System with CSS Custom Properties (variables.css), Glassmorphism, 3D elevation tokens, responsive clamp() fluid typography, and animation keyframes (animations.css, style.css).
- JavaScript (ES6+): Pure Vanilla JavaScript with asynchronous Fetch API, Drag-and-Drop file handling, DOM mutation localization, IntersectionObserver scroll animations, and localStorage theme/language persistence (main.js, upload.js, i18n.js, theme-toggle.js, animations.js).
- 3D WebGL Visualization: Three.js (r128) WebGL engine powering an interactive 360-degree Smart Tree architecture visualizer (tree3d.js).
- Typography / Fonts: Google Fonts (Inter, Outfit, Noto Sans Devanagari, Plus Jakarta Sans).

Backend:
- Web Framework: Python Flask (v3.1.3).
- WSGI Server: Werkzeug (v3.1.8) and Gunicorn (v26.0.0).
- Session Management: Flask client-side signed cookie sessions with Werkzeug secure utilities.
- Environment Management: python-dotenv (v1.2.2).

AI / Machine Learning:
- Cloud Vision AI: Google Gemini Vision API (`google-genai` v2.17.0 / `google-generativeai` legacy SDK) targeting models `gemini-3.6-flash` / `gemini-2.5-flash`.
- Deep Learning Framework: TensorFlow (v2.21.0) & Keras (v3.15.1).
- Convolutional Architectures: EfficientNetB0 (two-stage fine-tuning) & MobileNetV2 base models.
- Machine Learning Utilities: scikit-learn (v1.6+ metrics: Precision, Recall, F1-Score, Confusion Matrix), NumPy (v2.5.1), h5py (v3.14.0).
- Explainable AI (XAI): Grad-CAM (Gradient-weighted Class Activation Mapping) via TensorFlow GradientTape and OpenCV saliency visualizer fallback.

Computer Vision & Image Processing:
- OpenCV: `opencv-python` and `opencv-python-headless` (v5.0.0.93) for HSV color space transformations, morphological operations, Laplacian blur calculation, Gaussian filtering, adaptive thresholding, and contour overlays.
- Pillow (PIL): `Pillow` (v12.3.0) for image loading, validation, format verification, resizing, and RGBA-to-RGB normalization.

Database:
- Primary RDBMS: MySQL (via `PyMySQL` v1.2.0 with DictCursor).
- Embedded Fallback RDBMS: SQLite3 (built-in Python standard library with Row factory).
- Schema Migration: Dynamic schema synchronization and table alter logic inside `database/database.py`.

APIs & External Services:
- Google AI Studio Gemini API endpoint.

Libraries & Utilities:
- Requests (v2.34.2), HTTPX (v0.28.1), Rich (v15.0.0), Pydantic (v2.13.4), TQDM (v4.70.0), Jinja2 (v3.1.6).

Deployment:
- Linux (Kali Linux, Ubuntu, Debian, RHEL) / Gunicorn / Nginx / Docker compatible.

10. IMAGE DETECTION / AI WORKFLOW
================================================================================
Stage 1: Image Selection & Client Pre-Validation
- User drops or selects an image in `/detect` (or clicks one of the 4 quick test sample leaves).
- Client-side validation verifies extension (.jpg, .jpeg, .png, .webp) and file size (< 10MB).
- FileReader generates an instant in-browser preview inside the laser scanning viewfinder.
- User clicks "🔬 Analyze Crop Image".

Stage 2: Asynchronous API Dispatch & Loading Overlay
- `upload.js` displays full-screen loading modal (`#loadingOverlay`).
- Progressive 4-step loading sequence executes:
  1. "Processing image..."
  2. "Analyzing visible symptoms..."
  3. "Identifying possible disease..."
  4. "Preparing recommendations..."
- Multipart FormData containing `file` and `lang` (`en`, `mr`, or `hi`) is POSTed to `/api/analyze-leaf`.

Stage 3: Server-Side Validation & Ingestion
- `app.py` receives request at `/api/analyze-leaf`.
- Filename is sanitized with `werkzeug.utils.secure_filename`.
- Temporary preview file is saved to `static/uploads/leaf_preview_<timestamp>_<filename>`.
- `crop_analyzer.validate_image()` checks byte integrity and verifies readability with Pillow (`Image.open().verify()`).

Stage 4: Google Gemini Vision AI Processing
- `crop_analyzer.analyze_leaf()` converts image to RGB JPEG buffer.
- `_build_prompt()` generates a strict agricultural system prompt specifying target language (English, Marathi, or Hindi) and enforcing exact JSON schema.
- Gemini API (`gemini-3.6-flash` or `gemini-2.5-flash`) is invoked with `temperature=0.2` and `response_mime_type="application/json"`.
- Response text is parsed and stripped of markdown code blocks.
- Non-leaf check: If `valid_image == false`, API returns HTTP 400 error (`IMAGE_NOT_SUITABLE`).

Stage 5: Normalization & Persistence
- Data is normalized via `_normalize_analysis_response()` to ensure zero missing keys.
- Elapsed processing time is recorded.
- Diagnostic record and full JSON payload are safely logged to `prediction_history` table via `db_manager.save_prediction()`.
- Result payload is stored in Flask `session['gemini_analysis']`, `session['gemini_preview_img']`, `session['gemini_pred_id']`.
- JSON response `{ success: true, redirect_url: '/gemini-result', data: ... }` is returned to browser.

Stage 6: Rendering Report
- Browser receives JSON and executes `window.location.href = data.redirect_url`.
- `gemini_result()` route renders `templates/result.html` with full pathology report.

Local Offline CNN Inference Alternative (/predict):
- If using `/predict`, `model/predict.py` executes:
  1. `validate_image_file()` (existence, size, PIL verify).
  2. `preprocess_image_for_model()` (OpenCV load, BGR->RGB, resize to 224x224, normalize to [0,1], expand batch dimension).
  3. `image_quality.analyze_quality()` (Laplacian variance blur check, HSV brightness/contrast, foliage greenness ratio). If not leaf-like, rejects immediately.
  4. TensorFlow Keras model predicts 38-class softmax distribution.
  5. Computes Top-3 class breakdown and calibrated confidence level (Very High, High, Moderate, Low).
  6. `segmentation.segment_leaf_and_lesions()` isolates leaf mask via HSV, extracts brown/yellow necrotic lesions, calculates affected percentage, assigns severity band (Very Low, Low, Moderate, High, Severe), and outputs segmentation mask overlay.
  7. `gradcam.generate_gradcam()` calculates GradientTape gradients on last Conv2D layer, pools weights, applies JET colormap, and superimposes heatmap onto leaf image.
  8. Saves prediction to database and redirects to `/result/<prediction_id>`.

12. OPENCV / PILLOW USAGE
================================================================================
OpenCV (`cv2`) Usage:
1. `utils/image_processing.py`:
   - `cv2.imread(image_path)`: Loads image matrix from disk in BGR format.
   - `cv2.cvtColor(cv_img, cv2.COLOR_BGR2RGB)`: Converts BGR matrix to RGB tensor format for neural inference.
   - `cv2.resize(rgb_img, target_size, interpolation=cv2.INTER_AREA)`: Resizes image to 224x224.
2. `image_quality.py`:
   - `cv2.cvtColor(cv_bgr_image, cv2.COLOR_BGR2GRAY)`: Converts image to single-channel grayscale.
   - `cv2.Laplacian(gray, cv2.CV_64F).var()`: Computes variance of the Laplacian to evaluate image focus and blur score (threshold: 80.0).
   - `cv2.cvtColor(cv_bgr_image, cv2.COLOR_BGR2HSV)`: Converts to HSV color space.
   - HSV V-channel mean extraction for under-exposure (<40) and over-exposure (>220) detection.
   - Grayscale standard deviation (`np.std(gray)`) for contrast checking (<25.0).
   - Green foliage HSV thresholding (`cv2.inRange(hsv, [20,30,30], [90,255,255])`) + brown foliage mask (`cv2.inRange(hsv, [10,30,30], [30,255,255])`) to calculate leaf pixel ratio for non-leaf out-of-distribution rejection.
3. `segmentation.py`:
   - Foliage area segmentation via HSV range `[5, 20, 20]` to `[95, 255, 255]`.
   - Morphological operations: `cv2.morphologyEx(leaf_mask, cv2.MORPH_CLOSE, kernel)` and `cv2.MORPH_OPEN` with an elliptical structuring element (`cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))`) to remove background noise.
   - Lesion segmentation via HSV range `[5, 40, 20]` to `[32, 255, 220]`.
   - Gaussian blur + adaptive thresholding (`cv2.adaptiveThreshold(blurred, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY_INV, 11, 2)`).
   - Bitwise intersection: `cv2.bitwise_and(lesion_mask_hsv, leaf_mask)`.
   - Mask blending: `cv2.addWeighted(cv_bgr_image, 0.4, red_mask, 0.6, 0)`.
   - Contour outline rendering: `cv2.findContours(lesion_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)` and `cv2.drawContours(overlay, contours, -1, (0, 255, 255), 1)`.
   - `cv2.imwrite()` to save visual segmentation masks.
4. `model/gradcam.py`:
   - Resizing heatmap matrices with `cv2.resize()`.
   - Colormap application with `cv2.applyColorMap(heatmap_uint8, cv2.COLORMAP_JET)`.
   - Visual heatmap overlay blending with `cv2.addWeighted()`.
   - Saliency visualizer fallback using Laplacian feature gradients and 2D Gaussian meshgrids.

Pillow (`PIL.Image`) Usage:
1. `services/crop_analyzer.py`:
   - `Image.open(io.BytesIO(file_bytes))`: Loads raw byte stream in-memory without temporary disk overhead.
   - `img.verify()`: Verifies image header and byte integrity to prevent corrupted file exploits.
   - Mode conversion: Converts RGBA, CMYK, Palette, and Grayscale images to RGB (`pil_img.convert('RGB')`).
   - `pil_img.save(buf, format='JPEG')`: Encodes image into clean JPEG buffer for Google Gemini API Part payload.
2. `utils/image_processing.py`:
   - `validate_image_file()`: Verifies image file readability.
   - Fallback loader if OpenCV fails on special character paths.
3. `dataset/prepare_dataset.py` & `dataset_analysis.py`:
   - Batch image loading, Lanczos high-quality resampling (`Image.Resampling.LANCZOS`), and image dimension verification.

15. DISEASE INFORMATION & AGRICULTURAL KNOWLEDGE
================================================================================
The platform contains verified agricultural knowledge across 38 crop disease categories. Representative crops and disease pathologies include:

1. Tomato (Solanum lycopersicum):
   - Tomato Early Blight (Alternaria solani): Fungal disease forming concentric target-spot dark brown lesions on older foliage surrounded by yellow halos.
     * Organic Remedies: Copper Octanoate, Bacillus subtilis bio-fungicide foliar sprays every 7-10 days.
     * Conventional Solutions: Mancozeb or Chlorothalonil protective fungicides.
     * Nutrient Guidance: Potassium and Calcium support cell wall strength; avoid excessive Nitrogen.
     * Environmental Risk: 24-29°C, high humidity (>80%).
   - Tomato Late Blight (Phytophthora infestans): Water mold oomycete causing rapid water-soaked leaf collapse, dark lesions, and white sporulation.
     * Organic Remedies: Bordeaux mixture (Copper Sulfate + Lime), Trichoderma viride.
     * Conventional Solutions: Systemic fungicides (Metalaxyl, Cymoxanil).
     * Environmental Risk: Cool, wet conditions (15-22°C, >90% humidity).
   - Tomato Bacterial Spot (Xanthomonas spp.): Water-soaked lesions turning dark brown with yellow halos; defoliation.
   - Tomato Leaf Mold (Passalora fulva): Pale green/yellow spots on upper leaf surface, olive-green velvety mold on undersides.
   - Tomato Septoria Leaf Spot (Septoria lycopersici): Small circular spots with dark brown margins and gray/tan centers.
   - Tomato Spider Mites (Tetranychus urticae): Yellow stippling/speckling and fine webbing on leaf undersides.
   - Tomato Target Spot (Corynespora cassiicola): Brown circular lesions with light brown centers.
   - Tomato Yellow Leaf Curl Virus (TYLCV): Upward leaf curling, marginal chlorosis, stunted bushy growth (vector: Whiteflies / Bemisia tabaci).
   - Tomato Mosaic Virus (ToMV): Mottling, light/dark green mosaic patterns, leaf distortion.
   - Tomato Healthy: Optimal foliage structure, vibrant green color, absence of lesions.

2. Potato (Solanum tuberosum):
   - Potato Early Blight (Alternaria solani): Concentric ring brown lesions on lower canopy leaves.
   - Potato Late Blight (Phytophthora infestans): Water-soaked gray-black lesions with white fungal sporulation on undersides.
   - Potato Healthy: Uniform green leaf blades, sturdy stems, absence of blight.

3. Bell Pepper (Capsicum annuum):
   - Pepper Bacterial Spot (Xanthomonas campestris pv. vesicatoria): Small water-soaked dark lesions causing premature defoliation.
   - Pepper Healthy: Glossy dark green leaves, sturdy stem branches.

4. Apple (Malus domestica):
   - Apple Scab (Venturia inaequalis): Olive-green to velvety brown-black spots on leaf surfaces.
   - Apple Black Rot (Diplodia seriata): Frogeye leaf spots (circular brown spots with purple margins).
   - Apple Cedar Apple Rust (Gymnosporangium juniperi-virginianae): Bright orange-yellow lesions with small black dots.
   - Apple Healthy: Uniform green foliage.

5. Corn / Maize (Zea mays):
   - Corn Cercospora Leaf Spot / Gray Leaf Spot (Cercospora zeae-maydis): Rectangular, narrow grayish lesions bounded by leaf veins.
   - Corn Common Rust (Puccinia sorghi): Reddish-brown elongated pustules on both leaf surfaces.
   - Corn Northern Leaf Blight (Exserohilum turcicum): Long, elliptical, grayish-green to tan cigar-shaped lesions.
   - Corn Healthy: Sturdy green leaf blades without pustules.

6. Grape (Vitis vinifera):
   - Grape Black Rot (Guignardia bidwellii): Small reddish-brown circular spots with dark borders.
   - Grape Esca / Black Measles (Phaeomoniella chlamydospora): Interveinal chlorosis and necrosis ("tiger-stripe" pattern).
   - Grape Leaf Blight (Pseudocercospora cladosporioides): Irregular dark brown lesions.
   - Grape Healthy: Robust green vine leaves.

7. Other Supported Crops:
   - Blueberry (Healthy), Cherry (Healthy, Powdery Mildew), Orange (Citrus Greening / Huanglongbing), Peach (Bacterial Spot, Healthy), Raspberry (Healthy), Soybean (Healthy), Squash (Powdery Mildew), Strawberry (Leaf Scorch, Healthy).

21. INPUT VALIDATION
================================================================================
Frontend Validation:
- File Existence: Checks that a file is selected before enabling submission.
- File Extension: Whitelist checking for `.jpg`, `.jpeg`, `.png`, `.webp`.
- MIME Type: Whitelist checking for `image/jpeg`, `image/png`, `image/webp`.
- File Size Limit: Rejects files larger than 10,485,760 bytes (10 MB) with descriptive error toast.
- Contact Form: Regex email validation (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`) and required field checks.

Backend Validation:
- Flask Request Parsing: Validates presence of `file` or `image` in `request.files`.
- Filename Sanitization: `werkzeug.utils.secure_filename(file.filename)`.
- Extension Whitelisting: `utils.image_processing.allowed_file()` checks against `ALLOWED_EXTENSIONS = {'jpg', 'jpeg', 'png', 'webp'}`.
- Payload Length: `MAX_CONTENT_LENGTH = 10 * 1024 * 1024` enforced by Flask/Werkzeug (HTTP 413 on breach).
- PIL Image Verification: `Image.open().verify()` verifies genuine image byte encoding to protect against polyglot or malformed upload exploits.
- Non-Leaf Detection:
  * Gemini Cloud Vision: Returns `valid_image: false` if photo contains unrelated objects, animals, vehicles, people, or extreme blur.
  * Local OpenCV Pipeline: `image_quality.py` computes foliage color ratio; if green+brown pixel ratio < 8.0% or blur Laplacian variance < 80.0, marks `is_usable = False` and rejects.

================================================================================
22. ERROR MESSAGES & HANDLING
================================================================================
Standardized Error Codes & Messages:

1. `IMAGE_NOT_SUITABLE` (HTTP 400):
   - Trigger: Uploaded file is non-leaf, extremely blurry, severely underexposed, or corrupted.
   - Message: "Please upload a clear close-up image of the affected crop leaf."

2. `GEMINI_API_KEY_MISSING` (HTTP 401):
   - Trigger: `GEMINI_API_KEY` is not set or equals default placeholder in `.env`.
   - Message: "Gemini API key is not configured. Please set GEMINI_API_KEY in your environment or .env file."

3. `INVALID_API_KEY` (HTTP 401):
   - Trigger: Gemini API returns authentication failure.
   - Message: "Invalid Gemini API key provided. Please check your GEMINI_API_KEY configuration."

4. `RATE_LIMIT_EXCEEDED` (HTTP 429):
   - Trigger: Google Gemini API quota or rate limit exceeded.
   - Message: "Gemini API quota or rate limit exceeded. Please wait a moment and try again."

5. `REQUEST_TIMEOUT` (HTTP 500):
   - Trigger: Gemini API network request times out.
   - Message: "Gemini API request timed out. Please try again with a smaller clear leaf image."

6. `GEMINI_API_ERROR` (HTTP 500):
   - Trigger: Unhandled exception during GenAI SDK invocation.
   - Message: "Gemini vision analysis service error: <error details>"

7. `SERVER_ERROR` (HTTP 500):
   - Trigger: Internal unhandled server exception.
   - Message: "We couldn't analyze this image. Please try again with another clear crop leaf image."

8. HTTP 404 (Not Found):
   - Handled by `page_not_found(e)` in `app.py`. Renders `base.html` with error title "404 - Page Not Found".

9. HTTP 413 (Payload Too Large):
   - Handled by `request_entity_too_large(e)` in `app.py`. Returns JSON `{ "success": false, "error": "File size exceeds maximum 10MB limit." }`.

23. SECURITY / AUTHENTICATION
================================================================================
Security Mechanisms Implemented:
- User Authentication: Not implemented (Open access public diagnostic tool; no user login or passwords required).
- API Keys & Credentials: All keys loaded via `os.environ.get()` through `python-dotenv`. Default values provided as placeholders. Hardcoded secrets are avoided. Sensitive values represented as `[REDACTED]`.
- Session Security: Signed Flask client session cookies using `SECRET_KEY` configured in `.env`.
- Upload Security:
  * Sanitization via `secure_filename()` preventing directory traversal attacks (`../../`).
  * Explicit file extension whitelisting (`ALLOWED_EXTENSIONS`).
  * In-memory byte verification using PIL (`Image.verify()`) preventing malicious executable uploads disguised as images.
  * Size caps enforced at 10 MB (`MAX_CONTENT_LENGTH`).
  * Immediate error-cleanup: If analysis fails, temporary preview images in `static/uploads/` are purged from disk.
- Database Query Security: 100% Parameterized queries across both MySQL and SQLite (`?` for SQLite, `%s` for PyMySQL) preventing SQL injection vulnerabilities.

24. DATABASE ARCHITECTURE
================================================================================
Database Management Engine: `DatabaseManager` (`database/database.py`)
- Dual-mode architecture: Attempts connection to MySQL (`agrivision_db`). If MySQL server is unavailable or connection times out (3 seconds), automatically falls back to SQLite (`database/agrivision.db`).
- Auto-migration on startup: Dynamically inspects tables and adds missing columns (`confidence_level`, `image_quality`, `affected_area_pct`, `severity_band`, `full_analysis`).
- Auto-seeding: Automatically seeds SQLite with verified crop and disease records if tables are empty.

25. API DOCUMENTATION
================================================================================
--------------------------------------------------------------------------------
Endpoint: POST /api/analyze-leaf
--------------------------------------------------------------------------------
- Purpose: Executes cloud-based Google Gemini Vision AI crop health analysis.
- Content-Type: `multipart/form-data`
- Headers: Standard HTTP headers.
- Request Parameters (Body):
  * `file` (Binary File, required): Image file (JPG, JPEG, PNG, WEBP, <= 10MB).
  * `lang` (String, optional): Target language code ('en', 'mr', 'hi').
- Response Format: JSON
- Success (HTTP 200):
  ```json
  {
    "success": true,
    "redirect_url": "/gemini-result",
    "image_url": "/static/uploads/leaf_preview_1770695000_sample.jpg",
    "data": { ... full pathology JSON ... }
  }
  ```
- Error Responses:
  * 400 Bad Request: Missing file, unsupported format, or non-leaf image.
  * 401 Unauthorized: Missing or invalid Gemini API key.
  * 413 Payload Too Large: File exceeds 10MB limit.
  * 429 Too Many Requests: API rate limit or quota exceeded.
  * 500 Internal Server Error: Gemini SDK exception or internal error.

--------------------------------------------------------------------------------
Endpoint: POST /predict
--------------------------------------------------------------------------------
- Purpose: Executes local CNN inference with Grad-CAM and lesion segmentation.
- Content-Type: `multipart/form-data`
- Request Parameters (Body):
  * `file` (Binary File, required): Image file.
- Response Format: JSON
- Success (HTTP 200):
  ```json
  {
    "success": true,
    "prediction_id": 15,
    "redirect_url": "/result/15",
    "crop_name": "Potato",
    "disease_name": "Potato Early Blight",
    "confidence": 91.5,
    "confidence_level": "Very High",
    "image_quality": "Good",
    "affected_area_pct": 18.2,
    "severity_band": "Low",
    "status": "Disease Detected",
    "image_url": "/static/uploads/leaf_1770695000_sample.jpg",
    "heatmap_url": "/static/uploads/heatmap_leaf_1770695000_sample.jpg",
    "disease_info": { ... }
  }
  ```
- Error Responses:
  * 400 Bad Request: Image quality check failed or non-leaf detected.
  * 500 Internal Server Error: Model inference failure.

--------------------------------------------------------------------------------
Endpoint: GET /set-language/<lang>
--------------------------------------------------------------------------------
- Purpose: Updates persistent session language.
- URL Parameter: `lang` ('en', 'mr', 'hi').
- Query Parameter: `json=1` (forces JSON response).
- Success (HTTP 200 JSON):
  ```json
  {
    "success": true,
    "lang": "mr",
    "translations": { ... }
  }
  ```
- Fallback: 302 Redirect to referrer URL.

--------------------------------------------------------------------------------
Endpoint: POST /history/delete/<int:prediction_id>
--------------------------------------------------------------------------------
- Purpose: Deletes a specific prediction record from the database.
- URL Parameter: `prediction_id` (Integer ID).
- Response: 302 Redirect to `/history` with flash notification.

31. KNOWN LIMITATIONS
================================================================================
1. Visual Similarity Overlap: Different fungal pathogens (e.g. Early Blight vs Septoria Leaf Spot) may exhibit visually similar early necrotic spots, requiring careful review of the alternative conditions listed.
2. In-Field Lighting Variations: Severe direct sunlight glare or extreme night-time shadows may lower image quality scores and necessitate re-taking photos.
3. Laboratory Confirmation: AI visual diagnosis cannot replace chemical tissue cultures, microscope spore analysis, or ELISA / PCR viral testing.
4. Chemical Dosages: The system deliberately recommends chemical active ingredients and classes rather than exact localized brand dosages; farmers must always consult official product labels.
5. Single-Leaf Focus: The current pipeline evaluates single leaf close-ups rather than wide-angle canopy aerial drone footage.

36. IMPORTANT IMPLEMENTATION DETAILS
================================================================================
- Decoupled Service Architecture: All GenAI logic is encapsulated inside `services/crop_analyzer.py`, completely separate from routing in `app.py`.
- Dual GenAI SDK Compatibility: `crop_analyzer.py` detects both the modern `google.genai` SDK and legacy `google.generativeai`, switching syntax automatically.
- Stateless Backend Processing: Analysis requests process image byte streams directly; temporary preview images are tracked and can be purged without affecting database history.
- Non-Blocking Database Fail-Safe: In both `/api/analyze-leaf` and `/predict`, database save operations are wrapped in safe try/except blocks (`db_manager.save_prediction()`). A database connection error will never crash the prediction response or break the user experience.
- Automatic SQLite Migration: SQLite migrations run automatically inside `_setup_sqlite()` if new columns are added to the application models.

37. IMPORTANT UI DETAILS

- Fluid Sizing: Utilizes CSS `clamp(min, preferred, max)` to ensure buttons, fonts, and paddings scale seamlessly from 320px mobile screens up to 4K monitors.

- Context Processors: `app.py` registers `@app.context_processor` injecting `t()`, `translate_crop()`, `translate_disease()`, `translate_cat()`, `translate_status()`, `translate_sev()`, `translate_urg()`, `translate_conf()`, and `translate_tx()` into Jinja2 templates, ensuring template rendering is fully language-aware.

39. IMPORTANT AI/ML DETAILS
================================================================================
- Zero Hallucination Prompting: The Gemini prompt explicitly commands the model: "Do not claim certainty when visual evidence is insufficient. Do not invent laboratory results or exact confidence percentages. Use confidence labels: HIGH, MEDIUM, LOW. If the condition cannot be determined reliably, return UNKNOWN rather than guessing."
- Active Ingredient Enforcement: The prompt strictly forbids inventing brand names or unverified dosages, instructing the model to return active chemical ingredients and direct farmers to local label instructions.
- Grad-CAM Mathematics: Calculates gradients of top class score $y^c$ with respect to feature activation map $A^k$ of the final convolutional layer ($\frac{\partial y^c}{\partial A^k}$), computes global average pooled weights $\alpha_k^c = \frac{1}{Z} \sum_i \sum_j \frac{\partial y^c}{\partial A_{i,j}^k}$, computes weighted combination followed by ReLU activation: $L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$, and resizes to original input dimensions.
